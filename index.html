Computational tools for urban analysis

Morphological analysis

Developed from the ground up for urban analysis: assess the precursors to vibrant neighbourhoods using street-network centrality, land-use accessibility and mixed uses, spatial statistics, pedestrian-flow modelling, and street-level visibility.

Pedestrian scale

High-resolution analysis at the pedestrian scale with metrics computed at intervals along streetfronts: use network distances and spatial impedances for enhanced contextual sensitivity.

Friendly & performant

Python package with heavier algorithms implemented in parallelised rust code. I/O convenience methods for NetworkX with advanced cleaning methods for OSM data. Generated metrics stored as GeoPandas for export to common geospatial formats.
